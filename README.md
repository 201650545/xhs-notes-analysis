# 小红书点赞分析

> **定位**：定时任务「小红书点赞每日总结」完整工程。通过 kimi-webbridge 驱动真实浏览器 → 批量拉取点赞笔记 → 比对飞书 Base 历史库 → 唤起小红书「点点」多轮总结 → 自动生成本地报告并写回飞书多维表格 → 收尾清理浏览器标签页。
> 本项目为 Obsidian Work 库中的独立子项目，用于沉淀自动化流程、脚本工具链、排障经验及历史分析报告。

## 这是什么

小红书移动端/Web 端收藏与点赞是高价值知识获取的重要来源，但日常积累后易沉底腐烂。本项目打通自动化闭环：
1. **浏览器感知**：无需模拟登录与破解滑块验证码，通过 `kimi-webbridge` 守护进程驱动用户已登录的真实 Chrome。
2. **高效比对**：通过单次 JS 评估提取卡片元数据（带 `xsec_token`），与飞书多维表格已有历史精准比对 Note ID，增量为 0 时秒级静默退出。
3. **点点智能总结**：复用小红书内置 AI 助手「点点」（`https://www.xiaohongshu.com/ai_chat`），提取内容概要、主题分类与关键信息点。
4. **双向落盘**：结构化数据写入飞书多维表格（Base），Markdown 深度分析报告沉淀至本地，原始 AI 对话全量存档。
