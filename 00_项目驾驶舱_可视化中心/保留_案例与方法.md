## 案例 01｜把硬知识包装成"角色的旅行"

**来源**：小红书笔记「Claude 居然能直接生成教学视频」（笔记 ID 6ab3509e，2026-09 提取，原笔记已删）

**保留的是：一套知识视频的叙事骨架**（与工具无关，任何模型/任何题材都能套）

1. **用一个反差问题开场** —— 先抛出观众答不上来但天天见的现象（例：为什么赤道雨林茂密，撒哈拉却是沙漠）
2. **点出根本原因** —— 一句话给出底层驱动力（例：冷热不均）
3. **先给理想化假设** —— 把问题简化到最容易懂的形态（例：地球不自转、地表均匀 → 单圈环流）
4. **再逐个引入现实因素** —— 每加一个条件，复杂度升一级（例：加入地转偏向力 → 三圈环流）
5. **讲清机制如何形成** —— 说"为什么会长成这样"，不是罗列结论
6. **落到规律/分布** —— 给可记忆的结构（例：七个气压带、六个风带）
7. **加时间维度** —— 规律怎么随季节移动
8. **回到开场那个问题** —— 用它解释真实生活现象，形成闭环
9. **收尾编成口诀** —— 便于记忆和复述（例："冷热不均是动力，地球自转来偏转……"）

**关键的叙事手法**：全程用**第一人称拟人化**（"我是一团空气，你可以叫我小气团"），把抽象原理变成一次旅行。

**怎么用**：
- 脚本可以自己写或让 AI 写；配音走任意 TTS；画面交给已保留的 Flova
- 这套骨架不限地理，任何"原理型硬知识"都能套：物理、经济、算法、药物机制

**明确不保留的**：原笔记里的 Claude Opus 5.5（付费工具）、26 分钟耗时、具体提示词（原文未给出）

## 案例 02｜Video as Code：用前端代码直接"写"出产品宣传片

**来源**：小红书笔记「Opus 5.5 做产品宣传视频太牛了！」（笔记 ID 6ab546ee，2026-09-28 提取，原笔记已删）

**保留的是：一种不依赖剪辑软件和素材库的视频生产思路**

- 宣传片的画面动效用 **HTML + JS + Three.js** 写（3D/动效全在前端代码里），而非用剪辑软件逐帧做或用 AI 生视频工具抽卡
- **配乐和音效也全部由代码逐帧合成**，不调 Suno 等外部音乐 API——好处是音画可以精确同步，零素材成本
- 适用：产品功能演示、官网头图视频、信息流短片这类"动效即卖点"的内容；不适合写实人物镜头
- 关键习惯：把一次创作的参数与踩坑**沉淀成可复用 skill**（原作者项目名 guizang-product-video-skill），下次同类片子直接复用骨架

**怎么用**：
- 让任意强编码模型生成单文件 HTML（动效 + WebAudio 合成音效），屏幕录制或直接导出即成片
- 与案例 01 可组合：叙事骨架（案例01）写脚本，Video as Code（本案）出画面

**明确不保留的**：Opus 5.5 / GPT-6 Astra 的版本对比（会过时）、CodePilot 产品及其 17 家模型名单、具体提示词（原文未给）、无操作步骤（原文只有效果展示）

## 案例 03｜AI 数字人/角色视频的一致性技法

**来源**：小红书笔记「Vibe Coding 自制设计师个人网站」（笔记 ID 6aabddb0，2026-09 提取，原笔记已删；网站教程本身对我是降级方案，只留视频技法）

**保留的是：一套让 AI 生成的同一角色跨镜头不变脸、不跳位的硬规则**（与用什么生图/视频模型无关）

1. **衍生图只准动眼神和头部角度** —— 生成上下左右视向图时，提示词锁死：脸型、五官、发型、服饰、身体姿势、画面位置、人物大小、光线全部不变
2. **所有镜头共用同一张背景图** —— 额外上传背景并强调"共用"，否则背景光影纹理逐帧乱跳
3. **末帧闭环** —— 角色方向序列的最后一帧必须回到最初正面，否则循环衔接处卡顿
4. **按秒逐帧提反馈，不说"不够自然"** —— 问题必须定位到"第几秒位移／眼睛是否提前转向／头部角度是否过大／首尾帧对没对上"，再让模型改
5. **一次只改一类问题** —— 集中改一处、前后对比清晰，避免把已满意的部分改坏

**怎么用**：
- 适用：数字人口播、角色短剧、互动网页角色、Flova 流程里的角色一致性控制
- 与案例 02 互补：案例 02 解决"画面怎么生成"，本案解决"同一个人怎么不崩"

**明确不保留的**：Codex/Netlify 建站流程（我直接写代码即可）、Adobe Illustrator/香蕉Pro/Seedream 5.0/Seedance 2.0 等工具名（会过时）、三个灵感网站（Motionsites/Pinterest/React Bits）、原文未公开的完整提示词

## 案例 10｜儿童学习 App 的"开发逻辑×交互逻辑"（词根拆解三位一体）

**来源**：小红书笔记「小悦单词自然拼读App」（笔记 ID 6aba24750000000018011538，2026-10-12 提取，原笔记判删；
郭老师原话："它的开发逻辑、交互逻辑可以保留"）

**保留的是：一套低幼学习工具的产品设计逻辑**（与具体 App 无关，做儿童教育类应用可直接套）

1. **三位一体，不单点** —— 词根拆解＋音节拆分＋拼读，三条线绑在一起，缺一条就不成立
2. **多义与例句中英对照** —— 学一个词同时给"什么意思+怎么用"，不裸背单词
3. **AI 解析做兜底** —— 固定内容覆盖 80%，长尾疑问丢给 AI，不硬穷举
4. **练习巩固闭环** —— 学→练→测在一个循环里，不学完再考

**怎么用**：
- 他做听读/识字类课件或小程序时，交互按"拆解→对照→AI 兜底→练习"四步排
- 与案例 01（角色旅行叙事）可叠加：逻辑骨架用本案，表达层用 01

**明确不保留的**：小悦单词这个 App 本体（iOS/鸿蒙上架、安卓另找、拍照识别耗积分）、"国内首款免费"引流话术
