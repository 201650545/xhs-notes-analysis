## ★ v3 更新要点（2026-09-23 晚）

### 发送链路变更（决定性）

链接不再拼进提示词文本，而是先走**笔记卡片**：

1. 首页 → 点「问点点」展开面板
2. 链接写系统剪贴板 → CDP `Page.bringToFront`（焦点模拟，不抢窗口）→ CDP `Input.dispatchKeyEvent` 发物理 Ctrl+V → **1 秒生成笔记卡片**（`.xhs-ai-selected-note-card`，链接转为带 note_id 的附件实体）
3. `fill` 填入纯提示词（卡片保留）
4. 派发 **Enter**（点 ↑ 按钮始终无效）
5. 跳 `/ai_chat_tab?conversationId=…`，轮询 `.ai-message.ai-message-finished` ×2 次稳定后取 innerText

长度实测：纯文本模式 836 字静默失败/588 字成功；**卡片模式 783 字发送成功**（链接不占输入框容量）。
v3 模板字数：A 783 / B 767 / C 599 / D 559。

### v3 模板两个核心条款

**① 笔记/联网分区（所有类型统一前置）**

> 笔记信息不足时可以联网搜索公开资料补充，但必须分区标注——先写【笔记内容】（仅限笔记真实出现的信息），再写【联网补充】（搜索所得须注明来源，如 GitHub README、官网、媒体报道）。所有链接、GitHub 地址、数据都必须标明来自笔记还是联网，禁止混为一谈。

背景：v2 实测 A 类《Jev微信群聊》时，点点自行联网补了 3 个 GitHub 仓库地址却未与笔记内容区分。用户决策保留联网能力但强制分区。

**② 视频提示词原文摘录（所有类型必含一节）**

- A 类：摘录视频中实际输入给 AI 的提示词/指令，注明环节与工具
- B 类：摘录生图/生视频/剧本/配音提示词
- C 类：摘录提示词、文案模板、私信话术、操作指令
- D 类：摘录 AI 提示词、搜索词、软件指令、配方文本
- 统一兜底语：没有就写「视频中未出现提示词」，禁止编造

实测效果：B 类《手搓AI漫剧》成功抓到原文提示词**「不要加字幕」**（抽卡时加在结尾，避免模型生成错误字幕）；其余三条无提示词时均诚实标注。

## 0. 设计原则

1. **先分类、再提问**：不同类型笔记，点赞动机不同，想知道的东西不同，用不同提示词。
2. **防幻觉硬约束**：只基于笔记真实内容；没提到的必须写"笔记未提及"；名称/链接/数字原样照抄。
3. **分区标注**：联网补充必须与笔记内容分开并注明来源（v3 新增）。
4. **结构化输出**：固定编号小节，方便后续解析与沉淀。
5. **以"可复现/可照抄/可执行"为验收标准**：看完回答就能动手，而不是停留在概念。

## 1. 内容分类（四类）

| 类型 | 代码 | 识别关键词 | 点赞动机（想知道什么） |
|---|---|---|---|

## 2. v2 历史模板存档（以下为 v2 全文，仅供参考，实际以 v3 脚本为准）

```
你是一位资深 AI 技术拆解分析师。我给你一个小红书笔记/视频链接，请你认真观看、阅读其中的全部内容（视频画面、口播、字幕、配图、正文、评论区补充都要看到），然后做一次"可复现级"的深度拆解。

要求：
- 只基于笔记里真实出现的信息作答，严禁脑补、严禁编造链接或项目名；
- 凡是笔记里没有提到的信息，明确写"笔记未提及"，不要含糊带过；
- 出现的工具名、模型名、网站名、代码库地址，必须原样照抄，一个字符都不能错；
- 按下面的结构逐条回答，每条都要展开写充分，不要只给一句话。

一、这是什么（一句话定位）
用一句话说清这个笔记讲的是一个什么东西/项目/玩法，它解决谁的什么问题。

二、素材与想法（重点，写详细）
1. 原始素材：创作者用的是什么素材？（例如：什么数据、什么内容源、什么账号、什么音视频、什么 API、什么平台上的信息）素材从哪里来、怎么拿到的？
2. 核心想法/创意：他的核心想法到底是什么？请把这个想法的来龙去脉完整描述清楚——他看到了什么机会或痛点，想到了一个什么点子，打算用这个点子达成什么效果。
3. 想法的巧妙之处：这个想法为什么值得点赞？和普通做法相比，新在哪、省在哪、强在哪？

三、实现方式与技术原理（重点，分步骤）
1. 完整实现流程：从 0 到成品一共分哪几步？请按顺序列出每一步具体做什么。
2. 技术原理：背后依赖什么技术机制？（例如：浏览器插件读取页面、微信 hook、RAG 检索、Agent 编排、API 调用、定时任务、自动化工作流等）请把原理讲明白。
3. 关键环节拆解：整个流程中最核心、最有技术含量的环节是哪一步？它具体怎么运转的？

四、用到的 AI 与工具清单（逐个列出）
请把笔记中出现的每一个 AI 模型、AI 产品、编程工具、框架、插件、平台都列出来，并逐个写明：
- 准确名称（有版本号、型号名一并写出，例如 Kimi K2/K3、Claude Sonnet 4、Cline、Jev 等）；
- 它在流程里负责干什么；
- 是免费还是付费、大概价格（笔记提到才写）。

五、项目来源与链接（重点，必须逐条核对）
1. 笔记中是否提到 GitHub 开源项目、代码仓库或可下载地址？
   - 如果提到：原样给出完整 GitHub 地址（https://github.com/……），并说明这个仓库是做什么的、作者是谁；
   - 如果没提到：明确写"未提供 GitHub 地址"，不要编造。
2. 除 GitHub 外，笔记里还出现了哪些可点击的链接、公众号、群、文档、官网、飞书/网盘地址？请全部原样列出。
3. 如果内容是基于某个已有开源项目二次创作的，请指出原项目名称。

六、复现指南（如果我想自己做一个）
1. 前置条件：需要什么账号、什么环境、什么基础、大概多少成本；
2. 复现步骤：照着做的最简行动清单；
3. 难点与坑：笔记作者提到或能看出的坑、限制、风险（封号、收费、失效、技术门槛等）。

七、值得我收藏的一句话
用一两句话总结：我以后想用的时候，最该记住的关键点是什么。

笔记链接：{链接}
```

## 3. CAT_B · AI 内容创作/变现

```
你是一位资深 AI 内容创业拆解分析师。我给你一个小红书笔记/视频链接，内容是关于用 AI 做内容（AI 视频/AI 漫剧/AI 美剧/切片号等）并尝试变现的。请你认真观看全部内容（视频画面、口播、字幕、配图、正文、评论区都要看到），做一次"可照抄级"的深度拆解。

要求：
- 只基于笔记里真实出现的信息作答，严禁脑补；没提到的写"笔记未提及"；
- 工具名、平台名、金额、链接原样照抄；
- 按下面结构逐条展开，写充分。

一、这是什么（一句话定位）
创作者做了一个什么 AI 内容项目？最终成品长什么样、发在哪个平台？

二、创作素材与想法（重点，写详细）
1. 题材与内容：做的是什么故事/主题？什么风格（写实、动漫、影视感）？面向什么受众？
2. 素材来源：剧本、人物形象、配音、画面素材分别从哪来？是原创还是改编？
3. 核心想法：他为什么选这个题材/这种做法？核心创意和差异化是什么？

三、制作流程与实现方式（重点，分步骤）
1. 完整制作流水线：从选题到发布一共几步？每一步用什么做、怎么做，按顺序写清；
2. 关键技术环节：画面怎么生成、人物怎么保持一致性、口型/配音怎么对、视频怎么剪辑合成；
3. 一条/一集内容的实际制作周期。

四、用到的 AI 与工具清单（逐个列出）
每个工具写明：准确名称（含版本/型号）、负责哪个环节、免费还是付费、大概花费。
（例如：剧本用什么模型、出图用什么、视频生成用什么、配音用什么、剪辑用什么）

五、成本与收益账本（重点，数字原样照抄）

2. 产出：发了几条/几集、播放量、点赞、涨粉、红包/分成/广告等各项收入；
3. 算账：到底赚了还是亏了？单位成本和单位收益是多少？
4. 变现路径：钱具体是怎么拿到的（平台激励、中视频计划、带货、接单等）。

六、项目来源与链接
1. 是否提供 GitHub、模板、教程、工作流文件、提示词合集？有就原样给完整地址，没有写"未提供"；
2. 笔记里出现的其他链接、账号、群、文档全部列出。

七、复现指南
1. 新手照做的最简步骤；
2. 前置条件与启动成本；
3. 难点、坑和风险（限流、版权、账号权重、成本失控等）。

八、值得收藏的一句话
```
