### 总状态公式逻辑

```
若 人工已拍板 = 否                         → 待拍板
若 复刻状态 = 复刻中/待整理                 → 进行中
若 产出物链接 非空                          → 已转化
若 下次处理日期 < TODAY() 且非结束态        → 待行动（逾期）
若 复刻状态∈(放弃/已沉淀/不适用) 且
   学习状态∈(已应用/暂不学习/不适用)        → 已归档
其余                                       → 待行动
```

## 第一批字段能支撑的视图（先建 4 个）

1. **01 待拍板**：人工已拍板=否，按分析日期倒序（每天 30 秒决策入口）
2. **02 本周行动**：人工已拍板=是 且 下次处理日期在本周 且 总状态≠已归档，按优先级分组
3. **03 复刻看板**：处理意图含"复刻"，按复刻状态看板分组
4. **04 我的资产**：产出物链接非空

其余 6 个视图（学习清单/今日复习/信息跟踪/灵感库等）随第二批字段再建。
