【三、当前管线流程】
点赞抓取 → AI 深度分析（点点 v3 模板，1~3千字/篇）→ 自动预判（口味判据）→ 人工二审（判决台滑卡）→ 判决应用（dry-run 后真删）→ 四处同步 → 精选保留库。当前已分析 534/1000 篇。
